Théorie

Kotlin est un langage de programmation moderne utilisé pour développer des applications Android. Il permet de déclarer des variables avec des types de données spécifiques comme Int, String, Boolean, etc. Les fonctions sont des blocs de code réutilisables qui effectuent des tâches spécifiques.

Analogie

Imagine une cuisine : les variables sont comme les ingrédients (farine, sucre, œufs), chaque ingrédient a un type (solide, liquide). Les fonctions sont comme les recettes qui utilisent ces ingrédients pour créer un plat.

Créer une fonction simple

Écris une fonction qui prend deux nombres en paramètre et retourne leur somme.

Code de départ 
fun main() {
    // Déclare deux variables de type Int
    val a = 5
    val b = 10
    // Appelle ta fonction ici
}

Indices

  1. Commence par le mot-clé fun
  2. Déclare les paramètres entre parenthèses
  3. Utilise l'opérateur + pour additionner
Solution 
fun somme(a: Int, b: Int): Int {
    return a + b
}

fun main() {
    val a = 5
    val b = 10
    val resultat = somme(a, b)
    println("La somme est : $resultat")
}

1 Quel mot-clé utilise-t-on pour déclarer une variable modifiable en Kotlin ?

Explication

Le mot-clé var permet de déclarer une variable modifiable, contrairement à val qui crée une variable immuable.

2 Quel type de données est utilisé pour représenter du texte en Kotlin ?

Explication

Le type String est utilisé pour représenter du texte en Kotlin.

3 Comment appelle-t-on un bloc de code qui effectue une tâche spécifique et peut être réutilisé ?

Explication

Une fonction est un bloc de code réutilisable qui effectue une tâche spécifique.

J'ai oublié de spécifier le type de retour de ma fonction

Pourquoi : Kotlin est un langage typé statiquement qui nécessite de connaître le type de retour

Correction : Ajoute le type de retour après les parenthèses : fun nomFonction(): Int

J'ai utilisé val au lieu de var pour une variable que je veux modifier

Pourquoi : val crée une variable immuable qui ne peut pas être modifiée après sa déclaration

Correction : Utilise var pour les variables qui doivent être modifiées

J'ai oublié les deux-points entre le nom de la variable et son type

Pourquoi : En Kotlin, les deux-points (:) séparent le nom de la variable de son type

Correction : Ajoute les deux-points : var nomVariable: Type

Tu as appris à déclarer des variables avec var et val, à utiliser les types de données de base comme Int et String, et à créer des fonctions simples. Ces concepts sont fondamentaux pour la programmation en Kotlin.
