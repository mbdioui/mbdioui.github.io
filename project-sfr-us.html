SFR Gen8TV

Android TV — Set-Top Box streaming
SFR (via Mobiskill) Feb. 2021 — May 2022 Paris, France
Kotlin Android TV Jetpack Compose ExoPlayer CI/CD

Project overview

SFR Gen8TV is the Android TV Set-Top Box application deployed to over 5 million SFR customers in France. It centralizes live TV, replay, VOD and video streaming services.

Missions & features

Video streaming

  • Integration of ExoPlayer for video playback (live, replay, VOD).
  • Support for DRM (Widevine) and adaptive streaming formats.
  • Handling of trick modes and multilingual audio/subtitle tracks.
  • Management of network changes and recovery.

Android TV UI

  • TV-friendly interfaces using Jetpack Compose for TV and leanback components.
  • Focus navigation, remote control and D-pad optimization.
  • Voice command integration and accessibility support.

Quality and industrialization

  • Migration to Kotlin, MVVM architecture and Coroutines.
  • Unit tests (JUnit, Mockito) and automated UI tests.
  • CI/CD pipelines and delivery to SFR internal stores.
  • Crash analysis and performance monitoring (memory, ANR).

Results

  • Application deployed on millions of SFR TV boxes in production.
  • Significant reduction in playback and crash issues.
  • Improved release cadence via CI/CD pipelines.
