Project Details

Gen8TV: Official application for the 8th generation SFR Box. A complete Android Box experience for TV streaming and VOD.

Missions & Features

TV Features:
Development of program listings (current and evening), video stream management integration (live control, fast forward), and control fragments.

Interface & User Experience:
Creation of custom UI graphic components for television, graphic and functional corrections to ensure a smooth experience.

Methodology:
Work in an Agile Scrum team. Application supervision and adherence to component architectures.
