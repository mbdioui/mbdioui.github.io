Project Details

B2B logistics application for field agents at Elis, used daily to manage cleaning rounds, inventory, uniform collection, and pest control visits. Deployed internationally in Brazil, Canada, and Poland.

Key Features

Route Optimisation:
Route optimisation by vehicle type with Here SDK (V3/V4), respecting low-emission zones (ZFE), ETA calculation and tour planning.

Traceability & Inventory:
Inventory management with UHF, HF, NFC, 2D, QRcode. Compatible with Chainway and Zebra industrial PDAs. Proof of visit with photo capture and QR code assignment.

Real-time Synchronisation:
Real-time synchronisation with the back office for visit proofs, break/stop reporting, and inventory updates.

Refactoring & Performance:
Full refactoring from Java to Kotlin with RxJava and MVVM. Fixed all memory leaks and optimised cold start time.

Technologies

Native Android Kotlin/Java RxJava MVVM Here SDK V3/V4 NFC/RFID Zebra/Chainway SDK QR Code Real-time Sync
