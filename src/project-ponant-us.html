Project Details

Development of the Ponant luxury cruise mobile application for Infostrates.

Missions & Features

React Native From Scratch:
Full application development: navigation, state management with Redux and Context, JWT authentication, API calls with Axios, and fluid animations.

Mobile/Tablet Evolution:
Maintenance and evolution of the application on mobile and tablet, combining native Android development (Java/Kotlin) and React Native.

Quality & Testing:
Implementation of automated tests with Detox and Appium to ensure application robustness. Creation of a Web version via React Native Web.

Tech Stack

React Native Android (Java/Kotlin) Redux/Context Detox/Appium MVVM Git
