World Kids Athletics

Android App — Junior Athletics Coaching
NeoPixl Luxembourg Jul. 2025 — Jun. 2026 Differdange, Luxembourg
Kotlin Jetpack Compose MVI Bitrise Lead Tech

Project overview

Architected and built World Kids Athletics from scratch for NeoPixl Luxembourg: an Android application dedicated to junior athletics coaches. The project aimed to digitize athlete tracking, session planning and performance analysis in a structured sports environment.

Missions & features

Architecture and quality

  • MVI architecture with Jetpack Compose and Material 3.
  • Test coverage above 70%.
  • Integration of Detekt, Danger and SonarQube into the Bitrise CI/CD pipeline.
  • Performance and stress testing before delivery.

Android Lead Tech

  • Defined technical roadmaps and architecture choices.
  • Distributed tasks and tracked progress with Redmine.
  • Code reviews and mentoring of developers on Compose best practices.
  • UI alignment with Figma mockups.

Documentation and delivery

  • Wrote functional and technical documentation.
  • MVP delivered in 3 months with a satisfied client.
  • Functional CI/CD pipeline from the first release.

Results

  • MVP delivered on time with a satisfied client.
  • Tested, documented and industrialized application from day one.
  • Solid technical foundation laid for future evolutions.
