Project Details

Architected and built World Kids Athletics from scratch for NeoPixl Luxembourg: an Android application dedicated to junior athletics coaches.

Missions & Features

Architecture & Quality:
MVI architecture with Jetpack Compose, test coverage over 70%, integration of Detekt, Danger and SonarQube into the Bitrise CI/CD pipeline.

Lead Tech Android:
Defined technical roadmaps, distributed tasks, performed code reviews and mentored developers on Compose best practices.

Documentation & Delivery:
Documented functional and technical specifications in Confluence, tracked tasks in Redmine, aligned UI with Figma mockups. MVP delivered in under 3 months with satisfied client, performance and stress testing.
