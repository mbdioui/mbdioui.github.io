Introduction to Kotlin: variables, types and functions

Understand how to declare variables, know the basic types, and create simple functions in Kotlin.

Theory

Kotlin is a statically typed language that runs on the JVM. Variables are declared with the keywords val (immutable) or var (mutable). Basic types include Int, Double, Boolean, String, and Char. A function is defined with the keyword fun, followed by the name, parameters in parentheses, and a body in braces. The return type can be inferred or specified after a colon.

Analogy

Think of a variable as a labeled box: val indicates that the content cannot be changed once placed, while var allows opening and replacing the content. Types are like the size of the box: an Int can only contain whole numbers, a Double decimal numbers, etc.

Calculate the average of three numbers

1. Create a file main.kt. 2. Declare three variables val a, val b, val c of type Double and assign them any values. 3. Declare a variable var moyenne of type Double. 4. Calculate the average using the formula (a + b + c) / 3 and store it in moyenne. 5. Print the result with println(moyenne). 6. Run the program and verify that the output matches the expected average.

Starting code 
fun main() {
    // Declare three Double variables
    val a = 5.0
    val b = 10.0
    val c = 15.0
    // Calculate the average here
}

Hints

  1. Use the val keyword for values that do not change.
  2. Don't forget to convert literals to Double by adding .0 or using the syntax 5.0.
  3. The println function prints a line followed by a newline.
Solution 
fun main() {
    val a = 5.0
    val b = 10.0
    val c = 15.0
    val moyenne = (a + b + c) / 3
    println("The average is: $moyenne")
}

1 Which keyword declares an immutable variable in Kotlin?

Explanation

val creates a read-only reference, while var allows reassignment.

2 Which type should be used to store a decimal number with double precision?

Explanation

Double represents a 64-bit floating-point number, offering good precision for decimals.

3 In the function fun moyenne(a: Double, b: Double, c: Double): Double { return (a + b + c) / 3 }, what does it return?

Explanation

The expression (a + b + c) / 3 calculates exactly the arithmetic mean.

Using var for a value that never changes

Why : This works but goes against the immutability principle that makes code safer and more readable.

Fix : Prefer val when the value should not be reassigned after initialization.

Forgetting the decimal point when assigning a Double

Why : Without the point, Kotlin infers an Int type, causing a loss of precision or a type error if a Double is expected.

Fix : Add .0 or use scientific notation (e.g., 5e0) to force the Double type.

Confusing integer division and floating-point division operators

Why : In Kotlin, the / operator on two integers performs integer division, truncating the decimal result.

Fix : Make sure at least one operand is a floating-point type (Double or Float) before performing the division.
