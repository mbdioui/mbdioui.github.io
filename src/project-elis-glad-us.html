Project Details

This project is a native Android application developed for Elis, focused on logistics and traceability.

Key Features

Logistics:
Integration of HereWeGo mapping for route tracing, tour planning with route optimization, distance calculation, and ETA (Estimated Time of Arrival).

Traceability:
Inventory management and item detection using various technologies: UHF, HF, NFC, 2D, QRcode. Compatible with Chainway and Zebra industrial PDAs.

Proof of Visit:
Photo capture, QR code assignment, and full digitalization of business processes.

Technologies

Native Android HereWeGo Maps NFC/RFID Zebra/Chainway SDK QR Code
