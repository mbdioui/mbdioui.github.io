Ponant Companion

Application voyageur — Croisière de luxe
Infostrates Sept. 2020 — Nov. 2021 Marseille, France
Android React Native GraphQL Coroutines

Résumé du projet

Développement de l'application mobile Ponant Companion pour Infostrates. L'application accompagne les passagers à bord des bateaux de croisière de luxe Ponant, notamment lors du lancement du nouveau paquebot Commandant Charcot en Antarctique.

Missions et fonctionnalités

Mobile et tablette

  • Maintenance et évolution de l'application sur mobile et tablette.
  • Combinaison de développement Android natif (Java/Kotlin) et React Native.
  • Développement from scratch de fonctionnalités : newsletters, Room Services, camView.
  • Création d'une version Web via React Native Web.

Modernisation technique

  • Migration de RxJava vers Coroutines pour une code base plus lisible et performante.
  • Mise en place de feature flipping (avant/après voyage) pour activer progressivement les fonctionnalités.
  • Intégration de GraphQL pour les échanges avec les services backend.
  • Audit performance et propositions d'amélioration.

Qualité et collaboration

  • Tests automatisés avec Detox et Appium.
  • Recueil des besoins client, chiffrage et reporting.
  • Onboarding et mentorat de développeurs juniors/mediors.
  • Utilisation de Charles Proxy et Postman pour le debugging API.

Résultats obtenus

  • Lancement réussi du Commandant Charcot en Antarctique.
  • Respect des jalons et du budget projet.
  • Application stable et enrichie de nouvelles fonctionnalités embarquées.
