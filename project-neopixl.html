Détails du Projet

Conception et développement from scratch de World Kids Athletics pour NeoPixl Luxembourg : une application Android dédiée aux coachs d'athlétisme junior.

Missions et Fonctionnalités

Architecture et qualité :
Architecture MVI avec Jetpack Compose, couverture de tests supérieure à 70%, intégration de Detekt, Danger et SonarQube dans la pipeline CI/CD Bitrise.

Lead Tech Android :
Définition des roadmaps techniques, répartition des tâches, code reviews et mentorat des développeurs sur les meilleures pratiques Compose.

Documentation et livraison :
Rédaction de documentations fonctionnelle et technique, suivi des tâches dans Redmine, alignement UI avec les maquettes Figma. MVP livré en 3 mois avec satisfaction client, tests de performance et de stress.

Stack Technique

Kotlin Jetpack Compose MVI Bitrise SonarQube Detekt Danger Figma Sport REST API
