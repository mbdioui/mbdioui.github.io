Détails du Projet

Application Android officielle pour le set-top box SFR (GENT8TV), permettant l'affichage des programmes diffusés avec contrôle de lecture avancé.

Missions et Fonctionnalités

Listing des programmes :
Affichage des programmes en direct et enregistrés avec filtrage avancé (favoris, en cours, enregistrés).

Contrôle de lecture :
Intégration des commandes de lecture (rewind, fast-forward, continue watching) directement dans le flux vidéo principal via des fragments de contrôle.

Refonte UI :
Migration complète des layouts legacy vers ConstraintLayout et ViewBinding, interface plus fluide et réactive, meilleure maintenabilité du code.

Stack Technique

Android TV Kotlin Java ConstraintLayout ViewBinding Streaming/VOD MVVM
